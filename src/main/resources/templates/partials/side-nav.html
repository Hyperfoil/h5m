{@io.quarkiverse.roq.frontmatter.runtime.model.Page page} {@io.quarkiverse.roq.frontmatter.runtime.model.Site site} {! Content-driven side navigation. Each top-level folder under content/ is a menu, described by its index.md section page: - its `title` is the menu label and its `weight` the menu order. The other pages in the folder are the menu items, ordered by their own `weight`. So: - add a menu -> add content//index.md (with title + weight) - add an item -> add content//.md (with title + weight) No template edits, no separate nav file. Grouping/ordering is done by NavExtension (site.pages.sections / .items); Roq's built-in sortBy/filter only work on collection documents, not plain pages. Drafts are already excluded from site.pages by Roq.
