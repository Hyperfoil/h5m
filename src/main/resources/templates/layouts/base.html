Carbon Design System and Roq docs styles are built by Vite: - h5m-roq.scss → @carbon/styles (grid, type, tokens, g90 theme) + prose layout (injected by h5m-roq.js) - h5m-roq.js → @carbon/web-components (ui-shell, header actions, side-nav) Both @carbon/* packages come from node_modules, no CDN. !} {#if config:property('quarkus.profile') != 'dev'} {! Vite only emits h5m-roq.css on a production build; in dev the Vite-served h5m-roq.js injects the styles itself, and linking the file would hit Quinoa's SPA fallback and load index.html as text/html. !} {! h5m-roq.js is tiny and only imports carbon-wc (the ui-shell components that render cds-header / cds-side-nav). Without this the browser cannot start fetching the chunk until it has parsed the entry, delaying the shell by a whole round trip. In dev Vite serves unbundled modules, so there is no carbon-wc chunk to preload. !} {! The IBM Plex subsets the docs actually render with. They are declared inside h5m-roq.css, so without these the browser cannot even discover them until that 177 kB stylesheet has downloaded and parsed — and every @font-face is font-display:swap, so the page paints in the system fallback and then visibly reflows into Plex. Preloading starts them alongside the stylesheet instead, so they are usually there by the time it applies. Latin1 only, and only the weights the emitted rules use: 300 (heading-05/06), 400 and 600. The remaining 56 subsets (Latin2/3, Cyrillic, Pi, italics) stay lazy — unicode-range already keeps them off English pages. !} {/if} Documentation
